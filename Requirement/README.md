# Requirement

The public toolkit intentionally contains only generic integration requirements.

Before using it, provide your own:

1. Buyer/contact JSON matching the sample schema.
2. Legal sender identity and physical address.
3. Mail-provider SMTP/IMAP settings and application passwords.
4. OpenAI-compatible API credentials if AI drafting is required.
5. Suppression, unsubscribe, bounce, complaint, and reply handling.
6. Evidence that the intended data access and email use comply with applicable law, platform rules, and provider terms.

No maintainer production environment, account, domain, mailbox, company document, email template, or image is bundled here.
