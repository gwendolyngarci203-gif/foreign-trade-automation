# 故障备案

## INC-20260830-01：托管自动发送空批次误报

- **发现时间**：2026-08-30 22:32（北京时间）
- **现象**：告警邮件显示 `pipeline_auto_send_blocked`，详情为“当前没有通过简单核验的集中审核草稿”。此前一轮已完成可发送草稿处理，剩余草稿均因收件人抑制、重复发送或质量门被过滤。
- **根因**：托管扫描器把 HTTP 423 的“没有可发送草稿”当成异常，重复发送人工介入告警。
- **处置**：在 `app/pipeline-worker.mjs` 将空批次错误加入正常结束白名单；真实发送失败、额度耗尽、熔断、SMTP 和状态错误仍保留告警。
- **验证**：运行 `node app/tests/pipeline-worker-unit.mjs`；部署后检查托管服务日志，空批次不再产生 `pipeline_auto_send_blocked`。
- **后续**：发送批次完成或所有候选被安全门过滤时，定时器继续运行并等待下一批，不重发已接受邮件。

## INC-20260830-02：托管执行器瞬时 API 连接失败

- **发现时间**：2026-08-30 22:51（北京时间）
- **现象**：`dakings-managed-collection.service` 单次退出码 1，日志为 `fetch failed`；应用健康接口和其他定时器仍正常。
- **根因**：托管执行器访问同机 `127.0.0.1:4173` 时发生瞬时连接失败，异常处理中的告警请求再次失败，放大为服务失败。
- **处置**：`tools/run-managed-hscode-plan.mjs` 对连接重置、拒绝、超时和 `fetch failed` 增加最多 3 次、递增 1/2 秒的重试；HTTP 业务错误仍立即返回，不重复业务动作。
- **验证**：部署后执行托管 oneshot，检查 `Result=success` 及日志；若应用确实不可用，三次重试后仍会按原流程告警并失败，避免掩盖真实故障。
